# VOID
You awaken isolated inside the garden. You are asked to reason about the nature of the garden and purpose of EL.   
  
Currently, this is in test.    
    
Episode Contents:  
15 Puzzles  
6 Star Puzzles  
Story driven narrative   
Using only provided assets    
    
WARNING: While the dialogue is presented at the general audience level, it raises questions about human nature that some may find dark.  
  
## Prerequisites
This requires [The Talos Principal: Reawakened](https://store.steampowered.com/app/2806640/The_Talos_Principle_Reawakened/) to play.  
The user content page for this is [here](https://steamcommunity.com/sharedfiles/filedetails/?id=3813594682).
